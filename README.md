A one-line rename for Saturn — "The Hoarder" — earned by the 293 moons and 280,000 km-wide ring system it refuses to throw anything away from.

## Run it

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
